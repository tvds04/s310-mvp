Project Future

Welcome to Project Future! Please select an option below to register, apply, manage projects, or submit documents and feedback.

Submit Client Application

Register your business so your organization can propose a consulting project for a student team.

Submit Student Application

Apply to participate as a student consultant and upload your resume.

Create Project

Technology Consultants: enter project details and link a project to an existing client.

Form Teams

Managing Committee: assign accepted students to approved projects and set roles.

Submit Project Document Draft

Participants: upload draft documents for your Technology Consultant to review.

Submit Client Feedback

Clients: rate the team’s work and share comments after project delivery.

More tools (MC & TC)

  • Accept / Reject Project — review client project applications.
  • Accept / Reject Student Applications — review applicants.
  • Record Client Interview Details — log interview notes per project.
  • Submit Authorization Document — clients upload signed PDFs.
  • Send “Team Formed” Message — notify teams and clients.
  • Provide Document Feedback — TC review of drafts.
  • Submit Final Documents & Request Eval — participants close out deliverables.
